# TDD Loop

## Goal

Protect starter behavior with explicit red-green verification.

## Rules

1. write the failing test first
2. run the focused test and confirm the failure is expected
3. write the smallest implementation that passes
4. rerun the focused test
5. rerun the broader related suite
